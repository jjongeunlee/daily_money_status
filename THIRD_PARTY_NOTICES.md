# Korean holiday calendar

Generated from [date-holidays](https://github.com/commenthol/date-holidays), version 3.37.0, by commenthol and contributors. Holiday data is licensed under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/); program code is ISC licensed. The source KR calendar cites https://en.wikipedia.org/wiki/List_of_public_holidays_in_South_Korea.

Changes: selected Korean public holidays for 2020–2050, expanded multi-day spans, shifted the known Seollal span anchor by one day, and added explicitly listed election/temporary holiday dates in scripts/generate-holidays.mjs. Future exceptional dates and legal changes require updates.
